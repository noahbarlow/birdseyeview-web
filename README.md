# Bird's Eye View — Web

Static site for the Bird's Eye View Project (War Feather Program, 7X Project, documentary, et al.).

## Pages

- `index.html` — Homepage
- `program.html` — War Feather Program
- `how-it-works.html` — How It Works
- `impact.html` — Impact / Track Record
- `documentary.html` — After the Uniform documentary
- `get-involved.html` — Get Involved / Donations
- `apply.html` — Phase 1 application form
- `7x-project.html` — 7X Human Performance Project
- `logo-test.html` — Logo direction test sheet

## Local preview

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Stack

Plain HTML + CSS + a small dash of JS. No build step. Shared design system in `styles.css`.
